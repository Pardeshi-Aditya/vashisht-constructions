# Vashisht Constructions

A premium, production-ready builder portfolio website built with React 19, Vite, TypeScript, and Tailwind CSS v4.

## Tech Stack

- React 19 + Vite + TypeScript
- Tailwind CSS v4
- React Router
- Framer Motion
- Lucide React
- React Helmet Async
- Embla Carousel
- Netlify Forms

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy to Netlify

1. Push to a Git repository
2. Connect the repository to Netlify
3. Build command: `npm run build`
4. Publish directory: `dist`

Netlify Forms are configured via `public/contact-form.html` and the React contact form.

## Project Structure

- `src/components/` — Reusable UI components
- `src/constants/` — Company copy and configuration
- `src/data/projects/` — Individual project data files
- `src/pages/` — Route-level page components
- `src/assets/images/` — Local WebP images

## Customization

Update company details in `src/constants/company.ts` and add project data in `src/data/projects/`.

Replace placeholder images in `src/assets/images/` with your own WebP assets.
